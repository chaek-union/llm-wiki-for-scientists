# 부록 A. 도구별 설치와 설정

확인 기준일: 2026-08-05

이 부록의 내용은 본문보다 빨리 낡는다. 제품의 화면, 메뉴 이름, 설치 명령, 권한 설정은 몇 달 단위로 바뀐다. 기준일이 오래되었다면 아래 내용은 무엇을 확인해야 하는지의 목록으로만 쓰고, 실제 절차는 각 도구의 현재 문서에서 확인한다.

## 도구를 세 범주로 이해하기

제품 이름을 외우는 것보다 범주를 구분하는 편이 오래간다.

웹 대화 환경은 브라우저에서 질문하고 파일이나 연결된 자료를 쓰는 방식이다. 시작이 빠르고 준비가 적지만, ChatGPT 웹의 프로젝트는 컴퓨터의 로컬 폴더에 직접 접근하지 않는다. 결과가 대화와 프로젝트 자료에 남을 수 있으므로, 사용자의 로컬 파일 시스템에 기록되었다고 간주해서는 안 된다.

로컬 프로젝트 환경은 컴퓨터의 작업 폴더를 지정하고 그 안의 파일을 직접 읽고 고치는 방식이다. ChatGPT 데스크톱 앱의 로컬 프로젝트와 Codex 명령줄·편집기 확장이 여기에 속한다. 시작하려면 폴더와 지침 파일이 필요하고 결과가 파일로 남는다. 이 책이 다루는 작업 대부분이 이 방식에 속한다.

외부 도구 연결 환경은 대화나 로컬 프로젝트에 메일, 일정, 팀 문서 같은 서비스를 더한 방식이다. 같은 제품이 웹 대화, 로컬 프로젝트, 외부 도구 연결을 모두 제공할 수 있으므로 제품 이름만으로 범주를 정하지 않는다. 무엇이 로컬 파일에 남고 무엇이 서비스 안에만 남는지, 외부 상태가 바뀌었는지를 매번 확인한다.

## 구독을 운영 조건으로 두기

이 책과 같은 규모의 LLM-Wiki는 유료 구독을 전제로 한다. 무료 등급으로 짧은 실습을 시험할 수 있더라도, 수백 개 이상의 문서를 반복해서 읽고 고치며 장기간 운영하는 사용량을 안정적으로 확보하기 어렵다. OpenAI의 로컬 Codex에는 ChatGPT 구독 로그인과 API 사용량 결제라는 두 인증 경로가 있지만, API 경로도 무료가 아니며 ChatGPT 작업 공간이나 클라우드 기능에 기대는 일부 기능은 제한될 수 있다. Claude Cowork도 현재 유료 Claude 요금제에서 제공된다. 따라서 독자는 무료로 시작할 수 있는지만 보지 말고, 한 달 동안 실제로 수행할 폴더 작업의 횟수와 기능 범위를 기준으로 비용을 잡아야 한다. 구체적인 요금제 이름과 한도는 자주 바뀌므로 여기에 고정하지 않는다.

## 설치할 때 확인할 것

어떤 도구를 쓰든 다음 여섯 가지는 확인한다. 이 목록은 제품이 바뀌어도 유지된다.

첫째, 그 도구가 실제로 읽는 지침 파일의 이름이다. 도구마다 다르고, 같은 도구도 버전에 따라 다르다. 이름을 확인하지 않고 지침을 쓰면 규칙이 적용되지 않은 채로 작업이 진행된다.

둘째, 작업 폴더를 지정하는 방법과 그 범위다. 지정한 폴더의 상위나 하위까지 접근하는지, 심볼릭 링크를 따라가는지 확인한다.

셋째, 파일 수정 권한의 범위다. 읽기만 하는지, 쓰기까지 하는지, 삭제도 하는지, 그리고 각 동작에 사용자 승인이 필요한지 확인한다.

넷째, 외부 서비스 접근 권한이다. 웹 검색, 메일, 일정 같은 외부 연결이 기본으로 켜져 있는지 확인한다. 이 책이 다루는 방식에서는 웹 검색이 기본으로 꺼져 있어야 근거의 추적 가능성이 유지된다.

다섯째, 세션이 끝난 뒤 무엇이 남는지다. 대화 기록이 어디에 저장되는지, 파일 변경이 즉시 반영되는지 확인한다.

여섯째, 실행 환경과 색인 파일을 둘 위치다. 동기화 폴더 안에 실행 환경이나 색인을 두면 두 기기에서 동시에 쓸 때 충돌이 생긴다. 본문 3장에서 다룬 사고가 이 범주의 문제였다.

## 설치 확인 절차

도구를 설치한 뒤 다음을 순서대로 확인한다.

1. 빈 폴더를 만들고 그 폴더에서 세션을 시작한다.
2. 지침 파일에 눈에 띄는 규칙을 하나 적는다. 예를 들어 "모든 답변의 첫 줄에 현재 작업 폴더 이름을 적는다"처럼 지켰는지 바로 보이는 규칙이 좋다.
3. 새 세션을 열고 아무 질문이나 던져 그 규칙이 지켜지는지 본다. 지켜지지 않으면 그 도구는 그 파일을 읽지 않는 것이다.
4. 파일을 하나 만들게 하고 실제로 디스크에 생겼는지 확인한다.
5. 세션을 닫고 새로 열어, 대화 기록·프로젝트 문맥·기억 기능 가운데 무엇이 이어지는지 확인한다.

5번이 중요하다. 같은 폴더의 새 세션이 이전 내용을 반드시 잊는다고 단정할 수도 없고, 지난 결론을 정확히 이어받는다고 가정할 수도 없다. Codex의 로컬 기억은 별도 설정을 쓰며 기본적으로 꺼져 있고, ChatGPT 웹의 기억과도 별도의 저장소다. 따라서 프로젝트 운영에 필요한 상태는 파일에 남겨야 한다.

## 공유 채널의 구독과 조직 간 연결

확인 기준일: 2026-08-05

27장이 다루는 채널 배치는 개인 workspace 하나와 연구실 workspace를 잇는 구성이다. 구독은 연 단위로 하고, 교육 기관 할인을 적용하면 연간 요금이 3달러 수준이다. 요금제의 구성과 할인 자격 조건은 이 부록의 다른 항목보다도 자주 바뀌므로, 실제로 신청하기 전에 공급자의 현재 안내를 확인한다. 특히 교육 기관 할인은 소속 증빙과 심사를 요구하는 경우가 있고 적용되는 요금제가 한정될 수 있다.

조직 간 연결 기능은 한쪽에서 신청하는 것으로 열리지 않는다. 양쪽 workspace의 관리자가 각각 승인해야 채널이 이어지므로, 연구실 workspace의 관리자에게 어느 채널을 왜 잇는지 미리 설명해야 한다. 승인이 두 번 필요하다는 사실 때문에 연결은 즉시 열리지 않고, 채널 하나를 잇는 데 며칠이 걸릴 수 있다. 연결을 끊는 일도 같은 방식으로 양쪽에서 이루어진다.
